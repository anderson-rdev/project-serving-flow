# Projeto Final de Curso: SERVING FLOW

O **SERVING FLOW** é um sistema ERP (Enterprise Resource Planning), desenvolvido como projeto final de curso, voltado para restaurantes e pequenos comércios, como adegas, lanchonetes e mercearias. O principal objetivo é auxiliar na organização e no controle das atividades operacionais desses estabelecimentos.

## Objetivos do Sistema

O sistema proposto foca na automação e integração dos processos essenciais do negócio, permitindo:

- Cadastro de produtos
- Registro de vendas
- Controle de estoque
- Acompanhamento financeiro simplificado

Com isso, o **SERVING FLOW** visa proporcionar maior confiabilidade das informações, reduzir controles manuais e apoiar a tomada de decisões gerenciais.

## Desenvolvimento

O desenvolvimento do sistema será realizado em um ambiente acadêmico, utilizando um cenário fictício e respeitando as limitações e objetivos de um projeto educacional. O sistema contemplará apenas as funcionalidades fundamentais para o funcionamento de um ERP básico, priorizando simplicidade, usabilidade e coerência com a realidade de pequenos negócios.

## Funcionalidades do Projeto

O escopo do projeto inclui:

- Cadastro de usuários
- Cadastro de produtos e categorias
- Registro de vendas e formas de pagamento
- Controle de entrada e saída de estoque
- Acompanhamento financeiro simplificado
- Emissão de relatórios básicos para apoio à gestão
